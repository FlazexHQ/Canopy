First release of the DLS core and Canopy Realtime: the canopy.v1 protocol and EJSON-lite codec, an in-process
matcher verified against MongoDB, query validation with operator allowlists, the policy DSL and compiler, the
realtime engine with the canopy-realtime sidecar, the client read path with React bindings, and the
`canopy doctor` and `canopy policies lint|test` commands.
